# Agentic Brain — pa CLI (`pa/`)

Auto-loads on any read under `pa/`; carries pa-internal detail.

- **Locks & state**: `reservations.ts` claims are TTL-based, advisory, per-path; the `@build` reservation is auto-acquired by build/test (build-lock.ts — never claim by hand). The dist-identity guard (`assertDistFresh`) fails closed on stale dist — build before every test (`PA_ALLOW_STALE_DIST=1` is the bisect escape). Blackboard locks are PID+heartbeat with classifyLock eviction (dead→evict, alive+stale→grace that still blocks).
- **Maintenance runner in-flight guard is per-process; skip:in-flight is unreachable on the pa host (AI-196 closed-by-proof, 2026-09-03):** every pa-host process makes exactly one awaited `runDueJobs` pass — `pa catchup` holds its `catchup` blackboard lock around the call, and `pa maintenance run <job>` takes NO lock but runs one forced pass in its own process — so the per-process `IN_FLIGHT` set is empty at every production decision and the skip can never burn a due-check there. A bounded wait-and-redecide in runner.ts would poll a set that is always empty on that path: dead code, do not add one. Real residual: a catchup tick and `pa maintenance run` CAN execute the same job body concurrently across processes (no shared mutex; the guard is invisible cross-process) — a caller-level mutual-exclusion gap, not due-check loss, unfiled as of this date.
- **Mutate contract** (AI-177 fix): `reservations.mutate`'s fn returns `{result, logEntries}` — decision logs flush only AFTER the store write commits. `renew(id, {session})` is owner-checked. `safeLockOptions({compromisedPolicy})`: 'fail' tags + routes rejection for reservations (never throws from the timer).
- **Test discipline**: scoped runs via `npm test -- <bare-basename>`; the run-tests.mjs dark-file detector fail-closes on zero-test files; inherited `NODE_TEST_CONTEXT` can silently skip all files in spawned runners — NOT stripped by the runners (a test spawning the runner must delete it itself, see runner-env-scrub.test.ts). Both run-tests.mjs wrappers scrub deployment-env flags (`PA_RICH_MESSAGES` etc., list in `src/lib/test-env-scrub.ts`) from the suite spawn — `pa run` injects all secrets.env values into LLM-worker shells, so gate-run tests otherwise inherit live feature flags (AI-199: PA_RICH_MESSAGES=1 rerouted worker replies over /sendRichMessage and failed 12 subtests on every push-gate run). When running suites by hand, leave `PA_TEST_TMP_DIR` unset unless you mean to change the maintenance allowlist (a test pins its `C:/wt/tmp` default), and never point TMP/TEMP at a directory inside a git worktree — walk-up fixtures resolve the worktree's `.git` and their expected rejections go missing.
- **docs-lint trim counter** (`tests/docs-crossref.test.ts`, fix 305246a 2026-09-03): split detection = one memoized `git show --name-status -- '*.md'` probe per trim candidate (`A` status = split → counter reset); `git log --numstat` CANNOT mark new files (a created file reads as `added<TAB>0<TAB>path`, identical to an add-only modify, and the per-file query never lists the new file's row anyway). Commits stream OLDEST-FIRST (`--reverse`) so a split's reset clears only pre-split trims — newest-first leaves them counted when the split is the window's newest trim. Tool-layer gotcha found here: the old regex carried a literal backspace control byte where a `\b` escape was intended (written somewhere in its tool path), making it silently unmatchable — byte-scan source (`ord(c) < 32` sweep) when a "never matches" regex is suspected.
- **exec-fed sensors (c-disk-floor-watchdog, 2026-09-03):** `child_process.exec` routes through cmd.exe — a bare PowerShell expression fails (".Free was unexpected at this time"); wrap it `powershell -NoProfile -Command "..."` (the process-tree.ts:94 convention). And `Get-PSDrive` wants the drive name WITHOUT the colon: `Get-PSDrive C:` matches nothing, exits 0 with EMPTY stdout, and `Number('') === 0` turns that into a sensor reading of "0 bytes" that fires a real alert. Parse exec output strict-digits and embed the raw output in the throw — injected-execFn tests cannot see either class of bug; only the live CLI smoke crossed the seam.
- **public-sync's skip filter is FILE-shaped; tar directory members need their own handling (2026-09-04):** `git archive` emits a DIRECTORY member for every parent of an extracted file, and those members are never in `computeSkippedPaths`' output (check-ignore lists files only) — unhandled, a sync whose file skips all worked still leaves EMPTY directory husks of excluded trees in the mirror (pa-public carried empty `plans/` and `projects/fitness-data-sync/` after 2026-09-04 03:35 IST; the "filter didn't skip" report was these husks — 0 files under them). `extractHead` expands the skip list with slash-less ancestors and the python extractor compares the slash-stripped member name: **python's `tarfile` strips the trailing slash from directory `TarInfo.name` while `tar -t` display keeps it — never copy the display form into a member-name match.** Dir members also never count toward SKIPPED (privateHead counts blobs only). Fixture rule: a boundary fixture that excludes only single files (`*.secret`) can never see this; production's whole-tree patterns (`/*`, `projects/*`) are the shape to replicate.
